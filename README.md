# アリのコロニー フェロモン経路探索シミュレーション

アリが巣から食料源へのフェロモントレイルを通じて最短経路を発見するアリコロニー最適化（ACO）をリアルタイムで可視化。

## 機能

- アリ数 (10〜200)、蒸発率、フェロモン強度、α/β パラメータをスライダーでリアルタイム調整
- フェロモン強度をヒートマップで可視化し、発見された最短経路を黄色でハイライト
- クリックで食料源を移動、右クリックで障害物ブロック配置（Shift+右クリックで削除）
- 反復回数・最短経路長・食料到達回数などの統計をリアルタイム表示
- パラメータは localStorage に保存、ウィンドウリサイズ対応
